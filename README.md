# Markowitz Portfolio Optimization: Risk and Return Analysis

## Project Overview

This project applies **Markowitz Mean-Variance Portfolio Optimization** to investigate the relationship between portfolio risk and expected return using five selected U.S. stocks. The project was completed for the **Portfolio Theory and Risk Management** course.

The analysis uses **Microsoft Excel and Excel Solver** to calculate stock returns, portfolio risk, covariance, and Sharpe ratios, optimize portfolio allocations, and construct the efficient frontier.

## Research Objectives

1. How can Markowitz Mean-Variance Theory be used to construct an optimal investment portfolio?
2. Which portfolio allocation minimizes portfolio risk?
3. Which portfolio maximizes the Sharpe ratio?
4. How does the efficient frontier illustrate the relationship between portfolio risk and expected return?
5. What are the main assumptions and limitations of Modern Portfolio Theory?

## Dataset

The project uses daily closing price data for five U.S. stocks over approximately two months.

The selected stocks are:

- **Apple Inc. (AAPL)**
- **Microsoft Corporation (MSFT)**
- **Procter & Gamble Company (PG)**
- **Johnson & Johnson (JNJ)**
- **JPMorgan Chase & Co. (JPM)**

Daily stock returns were calculated from closing prices and used to estimate expected returns and the covariance matrix. A risk-free rate was incorporated into the Sharpe ratio calculations.

## Tools and Methods

**Tools:** Microsoft Excel, Excel Solver, and Excel STOCKHISTORY.

**Methods:**

- Historical stock return calculations
- Expected return and covariance matrix estimation
- Portfolio variance and standard deviation calculations
- Sharpe ratio analysis
- Minimum variance portfolio optimization
- Maximum Sharpe ratio portfolio optimization
- Maximum return portfolio analysis
- Efficient frontier construction
- Critical evaluation of Markowitz portfolio theory

## Key Findings

- Johnson & Johnson (JNJ) had the lowest standard deviation and the highest individual Sharpe ratio among the five selected stocks in the sample.
- The minimum variance portfolio achieved a reported portfolio standard deviation of approximately 0.6713%.
- The maximum Sharpe ratio portfolio allocated 100% of its weight to Johnson & Johnson under the selected data and optimization constraints.
- The efficient frontier illustrated the trade-off between portfolio risk and expected return.
- The analysis demonstrated the importance of diversification while highlighting the sensitivity of optimization results to historical data and model assumptions.

## Project Limitations

The analysis relies on a relatively short historical period of approximately two months. Expected returns and covariance estimates may therefore be sensitive to the selected sample. The model also relies on historical data, does not account for transaction costs, taxes, or market liquidity, and restricts short selling. Actual future returns may differ from historical estimates.

## Learning Outcomes

This project provided practical experience in quantitative finance, portfolio optimization, risk measurement, asset allocation, Excel Solver, Sharpe ratio analysis, and efficient frontier interpretation. It also strengthened understanding of how Modern Portfolio Theory can support investment decision-making and why its assumptions require careful consideration.
