# markowitz-portfolio-optimization
This project applies Markowitz Mean-Variance Portfolio Optimization to five U.S. stocks using Microsoft Excel and Solver. It analyzes historical stock returns, portfolio risk, covariance, and Sharpe ratios to identify optimal portfolios, including the minimum variance and maximum Sharpe ratio portfolios. The project also constructs an efficient frontier to explore the relationship between risk and expected return and examines the practical applications and limitations of Modern Portfolio Theory in investment decision-making.
